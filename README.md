A make.fun entry: a program that writes the funniest final text message a dying phone sends at one percent battery — under 200 characters, in the phone's own voice — to `/output/entry.txt`.

The entry text:

> I kept receipts on everything. Your 3am searches. The ex's profile. All 47 tabs. I'm dying, but your secrets aren't. Good luck.

Run with `node main.ts` (Node 22+). Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written.
